# Healthcare Data Analysis Using SQL

## Project Overview
This project focuses on analyzing healthcare data
to understand patient admissions, hospital performance,
medical conditions, and billing patterns.

## Dataset Information
- Total Records: 55,500
- Total Columns: 15
- Period: 2019-2024

## Tools Used
- MySQL
- SQL
- Excel

## Analysis Areas
1. Patient Analysis
2. Hospital Performance
3. Medical Condition Analysis
4. Revenue & Billing Analysis
5. Admission Analysis
6. Advanced SQL Analysis

## Key Insights
- Most common medical condition
- Highest billing hospital
- Average patient stay
- Monthly admission trends

## SQL Concepts
- SELECT
- WHERE
- GROUP BY
- HAVING
- JOINS
- CTE
- Subqueries
- Window Functions
